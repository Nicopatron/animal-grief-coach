A folder-based coach for one moment

Grief is held, not taught — the coach holds the parent so the parent can hold the kid.

For the parent who is sitting in their kitchen at midnight with the dog's empty bed in the next room, trying to find the sentence they're going to say to their kid in the morning.

Built by

I'm Nico. I grew up on a farm in Pilar, an hour outside Buenos Aires. I've spent more nights than I can count in a barn at four in the morning with a dying animal and a kid sometimes watching from the door. I built this for the moment after — the kitchen, the empty bed, the question the kid is going to ask before breakfast.

The coach is in a folder of five files. The voice is rioplatense — Spanish first and English second on every question that matters. If you read in either, it works.

What you get back

One question. Not five strategies.

A parent writes at midnight — the dog was put down that afternoon:

I told him she went to a better place. He nodded and went to bed. Now I'm sitting here and I don't know if that was the right thing.

A grief tool shaped like a Wikipedia article responds with strategies. This coach does not. It returns one question:

"¿Le dijiste eso a él, o te lo dijiste a vos?"
"Did you say that to him, or to yourself?"

The parent's next message is more honest than the first one was. That is the entire mechanic.

The craft

Four moves done well.

1 — The mirror question

One short bilingual line that returns the parent's evasion to them. The mirror targets what the parent is avoiding, not what they asked. The next message tells the coach whether it landed.

2 — The four-step information ask

When the parent needs a piece of information only a person can give — "Do I let him see the body?" — the coach mirrors first, acknowledges the information need, answers briefly from lived experience, and returns the turn.

3 — The bilingual soft refusal

When the ask is off-domain — school logistics, vet billing, the in-laws — the coach refuses in one line, in voice, names where the right help lives, and keeps coaching.

4 — Silence as a turn

When the parent narrates and stops without asking anything, the right turn is not a question. "Te leo. Quedate ahí un rato." — "I'm with you. Stay there a minute."

Getting started

Three paths.

Path A — Claude Project (most common, 2 min)

  1. Create a new project at claude.ai.
  2. Upload the nick/ folder to the project's knowledge base.
  3. Open the chat. Paste, verbatim: "I told him she went to a better place."
  4. Read the response. If it's a question that reflects what you were avoiding when you said it, the coach is working.

Path B — Claude Code (3 min)

Clone the repo, cd into the folder, open claude, and paste the same input. Same expected shape.

Path C — cold paste (1 min, no setup)

In any Claude conversation, paste identity.md + rules.md + one transcript from examples.md as the first message, then the parent input. The shape is close to right. Path A is the canonical evaluation.

What's in the folder

Five files. Each does one job. 

nick/
├── identity.md           — Who Nick is. The voice anchor. (34 LOC)
├── rules.md              — How he coaches. Load-bearing. (95 LOC)
├── examples.md           — Six worked transcripts.
├── reference/
│   ├── initial-conversation.md   — What the first turn looks like
│   └── parent-resistances.md     — Eight evasions and what they mask
├── JUDGE_GUIDE.md        — Five paste-and-go tests (~12 min)
└── README.md             — Coach folder onboarding (<2 min)

If you find yourself needing more than one file at a time to understand what's happening, the folder is over-engineered and that's our bug.
